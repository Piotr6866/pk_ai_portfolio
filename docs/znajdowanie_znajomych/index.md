
# Znajdowanie znajomych na kursie

Moje zadanie polegało na wdrożeniu aplikacji do znajdowania znajomych na kursie na platformę Streamlit Community Cloud.

<a href="app.py" class="md-button md-button--primary">Pobierz Kod projektu</a>

<script>
function resizeIframeToFitContent(iframe) {
    iframe.style.height = (iframe.contentWindow.document.documentElement.scrollHeight + 50) + "px";
    iframe.contentDocument.body.style["overflow"] = 'hidden';
}
window.addEventListener('load', function() {
    var iframe = document.getElementById('content');
    resizeIframeToFitContent(iframe);
});
window.addEventListener('resize', function() {
    var iframe = document.getElementById('content');
    resizeIframeToFitContent(iframe);
});
</script>
